# Mactician Release Notes — 1.3.1

- Bundle Vietnam (VNG) TFT 18.3-5530794 with the launcher, so Vietnam installs
  without a game download. An installed Vietnam game older than the bundled
  release is upgraded on launch.
- Add the Taiwan edition with independent downloads, updates, and sign-in
  alongside Global and Vietnam (VNG).
- Name the target patch on the update button ("Update to 18.4"), recheck the
  signed game feed every 30 minutes and when the app is reactivated, and add a
  "Check for game update" button in Settings. A game feed older than the
  installed game counts as up to date instead of failing the check.

Build 56 for Apple Silicon, macOS 12 or later. This build is signed ad hoc and
not notarized; open it through System Settings → Privacy & Security → Open Anyway.
